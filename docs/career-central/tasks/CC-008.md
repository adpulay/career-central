## Implementation

- `lib/email/controlled-sync.mjs`: validates observe-only configuration and opaque
  account identity, caps every CLI preview/sync at 24 hours, one page and 10
  metadata messages, validates account/scopes before Graph or health publication,
  and reuses the existing analyzer, coordinator and observation writer. It
  records a connected observation after token validation, with five-minute
  observation freshness (not token expiry or independent Graph verification).
- `scripts/outlook-email.mjs`: `first-sync --hours 1` combines normal Microsoft
  sign-in and inspection in one process, making session-only storage usable.
  Preview/sync also support explicit `--interactive`. Session-mode silent CLI
  use fails with an actionable category. Private identity-only migration is
  explicit and cannot replace an existing binding. Missing lock timing arguments
  in session/configuration paths are fixed. Legacy cache warnings happen before
  connection/reads; the file is never opened/deleted.
- OAuth: consumers/public client, PKCE/state and exact account check retained.
  Unexpected scopes/accounts fail before forwarding tokens; rejected cached
  accounts are removed with MSAL's actual `removeAccount` API. Disconnect now uses
  that API too (the old `clear` method was unsupported). Malformed scope arrays
  are refused; a pending OAuth timeout has an immediate rejection handler.
- Graph/analyzer: configurable page size with a hard provider-page bound,
  collection-only continuation, per-batch immutable-ID deduplication, strict
  received-time window checks and detail identity/date consistency. The CLI
  overrides old larger pagination settings. No remote write method exists.
- Private storage: native Windows DACL checks replace invalid reliance on POSIX
  modes; current-user ownership and allow rules limited to current user/SYSTEM
  are required. Linux owner/mode checks remain. Protected caches are precreated
  at 0600 on POSIX; existing unsafe files are refused. Native vendor validation
  is serialized for cooperating callers in one directory; pre-existing vendor
  scratch files are preserved/refused. No plaintext fallback or legacy migration.
- `scripts/outlook-vault-test.mjs`: user-run synthetic save/restart/verify/delete
  procedure, isolated service/account/subdirectory. Checks that the synthetic
  marker is absent from plaintext cache bytes. Does not open OAuth caches/config.
- `docs/OUTLOOK.md`: exact registration, session-only first read, MFA/consent,
  optional Windows DACL/DPAPI setup and WSL prerequisites; no assumed registration
  privilege, alias acceptance, sender authenticity or full-mailbox coverage.
